# 🐧 Configuración de Git en Linux

Guía paso a paso, limpia y rápida, para instalar, configurar y conectar Git con GitHub en sistemas operativos Linux (Ubuntu, Debian, Fedora, Arch Linux, entre otros).

---

## 📋 Prerrequisitos

Tener acceso a una terminal de Linux y privilegios de administrador (`sudo`) si vas a instalar paquetes desde el gestor de tu distribución.

---
